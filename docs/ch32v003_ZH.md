# CH32V003 IO 与 ADC

[English](ch32v003.md) | [简体中文](ch32v003_ZH.md)

板载 CH32V003 固件通过 SDA GPIO0 / SCL GPIO1 提供地址 0x24 的 I2C 接口，请保留该固件。

| 引脚 / 寄存器 | 板上用途 |
| --- | --- |
| EXIO0 | CST3530 复位 |
| EXIO1 | ST7789 复位 |
| EXIO2 | 保留，不作测试 |
| EXIO3 | 扬声器功放使能 |
| EXIO4 / EXIO5 | SHTC3 接口，不作测试输出 |
| EXIO6 / EXIO7 | 排针通用 IO |
| 寄存器 0x05 | 背光 PWM，0–255 |
| 寄存器 0x06 | 电池 ADC，两个字节，低字节在前 |

电池示例对八次 10 位采样取平均。标称电压为 `raw × 3.3 / 1023 × 3`，分压电阻按原理图的 200 kΩ / 100 kΩ 计算。参考电压、分压电阻和 ADC 公差会影响精度，该值不是电量百分比。

简单示例调用对应外设的独立初始化接口。CH32V003 驱动首次初始化会恢复默认 IO 寄存器；LCD/触摸复位及功放配置由各自 BSP 接口完成。
