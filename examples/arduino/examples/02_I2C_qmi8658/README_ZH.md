# QMI8658 运动传感器

[English](README.md) | [简体中文](README_ZH.md)

## 功能

在串口观察移动开发板时加速度和角速度的变化，屏幕不点亮。

## 硬件需求

ESP32-C5-Touch-LCD-2.8 开发板和 USB 数据线。使用板载传感器，无需外接模块。

## 怎么运行

1. 按 [Arduino 入门说明](../../../../docs/getting-started-arduino_ZH.md)安装环境、设置开发板和附带库，再打开本目录的 **`02_I2C_qmi8658.ino`**。
2. 使用 USB 数据线连接开发板。选择开发板串口，点击**上传**，完成后打开**串口监视器**，设为 **115200 波特率**，再按 RESET。
3. 先平放开发板，再轻轻倾斜和转动，观察串口数值变化。

## 预期现象

串口显示 x/y/z 加速度和 gyro_x/gyro_y/gyro_z 角速度，轻轻转动开发板可观察变化；屏幕保持黑屏。

## 常见问题

- **屏幕不亮：**结果只在串口显示。
- **静止时加速度不为零：**传感器仍会测到重力，倾斜开发板比较变化即可。
