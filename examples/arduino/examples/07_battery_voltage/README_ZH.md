# 电池电压显示

[English](README.md) | [简体中文](README_ZH.md)

## 功能

在屏幕和串口查看接入电池的电压。

## 硬件需求

ESP32-C5-Touch-LCD-2.8 开发板和 USB 数据线。将匹配电池正确接入电池座，接入前检查正负极。

## 怎么运行

1. 按 [Arduino 入门说明](../../../../docs/getting-started-arduino_ZH.md)安装环境、设置开发板和附带库，再打开本目录的 **`07_battery_voltage.ino`**。
2. 先断电，将电池按正确极性接好，再连接 USB。选择开发板串口，点击**上传**，完成后打开**串口监视器**，设为 **115200 波特率**，再按 RESET。
3. 查看屏幕电压，无需触摸操作。

## 预期现象

屏幕和串口约每秒更新一次，显示电压及 0-1023 的 ADC 值；这是电压值，不是剩余电量百分比。

## 常见问题

- **电压为零或异常：**断电后检查电池连接和极性，需要时与万用表比较。
- **没有电量百分比：**本示例只显示电压。
