# 扩展 IO

[English](README.md) | [简体中文](README_ZH.md)

## 功能

检查排针 EXIO6/7 输出，观察背光每秒一次的明暗变化。

## 硬件需求

ESP32-C5-Touch-LCD-2.8 开发板和 USB 数据线。可选用万用表测量 EXIO6/7 相对开发板 GND 的电平。

## 怎么运行

1. 按 [Arduino 入门说明](../../../../docs/getting-started-arduino_ZH.md)安装环境、设置开发板和附带库，再打开本目录的 **`01_exio.ino`**。
2. 使用 USB 数据线连接开发板。选择开发板串口，点击**上传**，完成后打开**串口监视器**，设为 **115200 波特率**，再按 RESET。
3. 观察背光明暗切换，也可用万用表测量 EXIO6/7 相对 GND 的电平。

## 预期现象

串口显示 EXIO6/7 电平及 0%/100% 背光交替变化，背光随之明暗切换，本示例不显示 LCD 界面。

## 常见问题

- **没有画面：**本示例只切换背光，不显示图案，属于正常现象。
- **应该测哪几个引脚？**测排针 EXIO6/7 与 GND，用途见[排针说明](../../../../docs/ch32v003_ZH.md)。
