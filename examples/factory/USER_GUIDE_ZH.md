# 出厂应用使用说明

[English](USER_GUIDE.md) | [简体中文](USER_GUIDE_ZH.md)

## 开始使用

本说明对应当前[出厂源码](README_ZH.md)。桌面为 240 × 320 竖屏，每页四个图标，左右滑动翻页；沿用原背景，应用名称和居中时间为白色，桌面首帧完成后开启背光。之前发布的 BIN 仍保留各自版本的行为。

## 连接 Wi-Fi

设备支持 2.4 GHz 和 5 GHz Wi-Fi，优先使用已保存的网络；没有保存记录时，连接任一频段的 `weather-wifi`，密码 `12345678`。

1. 打开 **Settings → Wi-Fi setup**，设备自动开启配网热点。
2. 扫描二维码，或按屏幕显示的名称及密码连接热点。
3. 打开 `http://192.168.4.1`，填写目标网络账号并提交。
4. 成功连接后保存账号并关闭设备热点；退出配网页面也会关闭热点。

配网热点与目标网络共用无线信道。连接 5 GHz 网络期间，如果手机断开设备热点，请查看设备屏幕的连接状态，或重新连接设备热点。

**Wi-Fi scan** 只扫描附近网络，不改变连接。SNTP 同步桌面的北京时间，未同步时显示 `--:--`；不会自动覆盖硬件 RTC 的日历。

## 应用操作

| 应用 | 操作 |
| --- | --- |
| Display Test | 红、绿、蓝、黄、白循环，每色一秒；400 ms 内在任意位置双击退出，使用本板的 LVGL 点击判断。 |
| Settings | 调节亮度与音量，查看 Wi-Fi 扫描、配网、SD 卡信息和 About。左上角箭头在子页返回设置首页，在设置首页返回桌面。 |
| AIChats | 联网后按提示激活；说“你好小智”或点击 **Talk** 开始，**Stop** 停止；支持语音调节音量和亮度，不包含摄像头工具。 |
| Touch Test | 全屏绘画检查四边触摸；左上角返回按钮或 BOOT 退出。 |
| GravityBall | 平放约两秒校准后，倾斜控制小球移动至屏幕四边；BOOT 重新校准。 |
| Photos | 浏览 SD 卡 `/photo` 内的 JPG/JPEG，左右滑动切换；240 × 320 图片更节省内存。 |
| Weather | 查看在线天气并手动刷新，保留原天气服务配置。 |
| Music | 播放 SD 卡 `/music` 内的 MP3，支持上一曲、下一曲、播放/暂停和进度控制。 |
| Sensor | 查看硬件 RTC、QMI8658 运动数据与 SHTC3 温湿度。 |
| 2048 | 滑动合并方块，顶部 **New** 重开；再次进入保留棋盘。 |
| Mic Test | 实时电平测试，**Record** 录音、**Stop** 停止、**Play** 回放；最长 10 秒，显示已用时间。 |
| Button Test | 先松开 BOOT，再按下并松开完成测试；**Test again** 重测。本板没有 PWR 测试输入。 |

除 Display Test 外，可从屏幕底部中间向上滑动返回桌面。同一时间只保留一个运行中的应用；退出音频应用会停止工作任务并释放共用 ES8311，音乐不会后台播放。

## 音乐与照片

开机前插入 FAT32 microSD 卡，在根目录建立 `/music` 放 MP3、`/photo` 放 JPG/JPEG。只扫描这两个目录中的文件，不递归扫描子目录；音乐不再读取 SPIFFS 内置曲目。缺卡后重新插卡，请重新打开 Music 或 Photos，应用不会格式化卡片。

Mic Test 将最长 10 秒的单声道 PCM 临时保存在 PSRAM，退出应用即清除，不写入 SD 卡或 Flash。电平监测不会实时外放麦克风声音。

## 编译与常见问题

按[工程说明](README_ZH.md)编译并完整烧录，包含应用、分区表和语音模型；保留的 SPIFFS 分区不参与新版音乐播放。

- **没有音乐或照片：**检查 FAT32、目录名与扩展名，再重新打开应用。
- **大图加载失败：**尝试 240 × 320 JPEG，可用 PSRAM 会限制解码尺寸。
- **Wi-Fi 已连接但在线功能不可用：**检查互联网连接及远端服务。
- **时间一直显示 `--:--`：**检查网络是否允许 SNTP 通信。
- **音频被占用：**关闭其他音频应用后重试。
- **串口乱码：**选择 2,000,000 波特率。
