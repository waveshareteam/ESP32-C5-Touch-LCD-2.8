# 出厂固件使用说明

[English](USER_GUIDE.md) | [简体中文](USER_GUIDE_ZH.md)

## 开始使用

本说明对应当前集成 AIChats 的新版出厂固件。通过 USB 数据线连接 ESP32-C5-Touch-LCD-2.8，启动后显示 240 × 320 竖屏桌面，左右滑动浏览应用，点击图标打开应用。

恢复软件参照[固件说明](../../firmware/README_ZH.md)，编译源码参照[工程说明](README_ZH.md)。从旧版升级需完整烧录，新版包含独立的 SPIFFS 资源和语音模型分区。

## 连接 Wi-Fi

当前版本启动时尝试连接演示热点 `weather-wifi`，密码 `12345678`。需要连接其他网络时：

1. 打开 **Settings → WLAN**，进入配网页面。
2. 扫描二维码，或连接屏幕显示的设备热点，密码为 `12345678`。
3. 保持连接设备热点，在浏览器打开 `http://192.168.4.1`，填写目标网络的名称和密码并提交。
4. 等待设备显示连接结果，再打开天气或 AIChats。

Wi-Fi 扫描用于查看附近网络信息。当前版本每次启动均尝试默认演示热点；临时配网不改变源码中的默认账号。连接互联网后通过 SNTP 同步桌面时间，时区为 UTC+8。

## 应用操作

| 应用 | 操作 |
| --- | --- |
| Settings | 调节背光，查看设备信息，在 WLAN 页面扫描网络及配网。 |
| AIChats | 联网后按屏幕提示和激活码完成绑定；说“你好小智”或点击 **Talk** 开始对话，点击 **Stop** 停止。可说“音量调到最大”或“亮度调到百分之五十”；亮度设为 0 会关闭背光。 |
| Sensor | 查看 RTC 时间、QMI8658 运动数据和 SHTC3 温湿度。 |
| Drawing | 在屏幕上绘画，检查触摸响应。 |
| 重力球 | 倾斜开发板，观察小球随姿态移动。 |
| MusicPlayer | 播放内置 MP3，使用播放/暂停及切歌按钮；曲目来自 SPIFFS 的 `/music`。 |
| Weather | 联网查看天气；沿用工程内置的服务配置。 |
| Games | 触摸滑动操作 2048 游戏。 |
| Photos | 浏览 microSD 卡 `/photo` 中的 `.jpg` 图片，左右滑动切换。 |
| Mic Test | 说话查看音量变化；点击 **Record** 录音，**Stop** 提前结束，**Play** 回放；最长 10 秒，界面显示录音或播放时长。 |

按应用返回按钮或桌面导航返回上一层。MusicPlayer、AIChats 和 Mic Test 共用 ES8311，切换前退出当前音频应用；当前版本不提供摄像头功能。

## 音乐与照片

出厂工程自带 `spiffs/music/BGM_2.mp3`，构建时生成 SPIFFS 镜像。替换或添加 MP3 后重新构建并完整烧录，单独烧录应用不会更新音乐资源。

Photos 使用 FAT32 microSD 卡，在卡根目录创建 `/photo`，放入 `.jpg` 图片，再打开相册。麦克风录音保存在 PSRAM，无需 SD 卡；退出 Mic Test 后录音清除，不会写入相册或 Flash。

## 常见问题

- **已连接 Wi-Fi，但天气或小智不可用：**检查热点能否访问互联网，以及相应远端服务是否可达。
- **AIChats 提示缺少模型：**烧录完整合并 BIN，或执行完整的 `idf.py flash`，包含语音模型和 SPIFFS。
- **串口乱码：**监视器使用 2,000,000 波特率。
- **相册没有文件：**检查 FAT32 格式、`/photo` 文件夹和 `.jpg` 扩展名，添加文件后重新打开相册。
- **音频被占用：**先退出其他音频应用，再进入所需应用。
- **Mic Test 没有保存录音：**录音只用于本次测试，关闭应用即清除，达到 10 秒会自动停止。
