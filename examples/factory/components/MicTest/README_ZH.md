# 麦克风测试

[English](README.md) | [简体中文](README_ZH.md)

## 功能

显示麦克风电平，在 PSRAM 中录制最长 10 秒的 16 kHz 单声道 PCM16。浅色界面显示录音及回放时间，提供 Record、Stop、Play 操作。

## 硬件需求

使用板载 ES8311、麦克风及扬声器，不需要 SD 卡。

## 怎么运行

完整编译[出厂工程](../../README_ZH.md)，打开 Mic Test 并说话。点击 Record 录音、Stop 提前结束、Play 回放。

## 预期现象

电平随声音变化，录音达到 10 秒自动停止。关闭应用会停止工作任务并释放共享音频会话。

## 常见问题

退出后录音清除，不会写入 Flash 或 SD 卡。实时监测不会通过扬声器播放，避免反馈啸叫。
