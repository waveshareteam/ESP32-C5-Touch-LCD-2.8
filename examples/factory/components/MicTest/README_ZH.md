# Mic Test

[English](README.md) | [简体中文](README_ZH.md)

## 功能

显示实时麦克风音量，支持最长 10 秒录音与扬声器回放，并显示录音及播放时长。

## 硬件需求

使用开发板 ES8311 麦克风和扬声器，不需要 SD 卡。

## 怎么运行

从出厂桌面打开 Mic Test，点击 Record 后说话，点击 Stop 可提前结束，再点击 Play 回放。

## 预期现象

音量条按 -60 至 0 dBFS 映射显示输入强度，时间标签显示 `0.0 / 10.0 s`、录音进度或播放已用/总时长。

## 常见问题

录音为 PSRAM 中的 16 kHz 单声道 PCM16，关闭应用后清除。请先退出 MusicPlayer 或 AIChats；实时音量监测不会直接播放麦克风声音。
