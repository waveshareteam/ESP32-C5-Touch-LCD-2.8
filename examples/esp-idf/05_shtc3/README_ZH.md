# SHTC3 温湿度

[English](README.md) | [简体中文](README_ZH.md)

## 功能

在串口监视器查看环境温度和湿度；屏幕不点亮。

## 硬件需求

ESP32-C5-Touch-LCD-2.8 开发板和 USB 数据线，使用板载温湿度传感器，无需 SD 卡或其他接线。

## 怎么运行

1. 首次使用按 [ESP-IDF 入门说明](../../../docs/getting-started-idf_ZH.md)准备环境，再在 **`05_shtc3`** 目录打开 ESP-IDF 终端。
2. 执行以下命令，第二条会烧录示例并以 **115200 波特率**打开串口监视器。

   ```sh
   idf.py build
   idf.py flash monitor
   ```

3. 将开发板放在需要测量的环境中，在串口监视器查看温湿度，无需触摸操作。

## 预期现象

串口每秒更新，例如 `25.00 C; 50.00 %RH` 表示温度 25℃、相对湿度 50%；实际数值会随环境变化。

## 常见问题

- **为什么屏幕不亮？**温湿度只在串口监视器显示。
- **数值看起来异常：**不要用手遮住、接触或弄湿传感器；若重新上电后仍提示读取失败，保留串口日志联系技术支持。
