# 电池电压显示

[English](README.md) | [简体中文](README_ZH.md)

## 功能

在屏幕和串口监视器查看接入电池的电压。

## 硬件需求

ESP32-C5-Touch-LCD-2.8 开发板、USB 数据线及匹配电池。

## 怎么运行

1. 先断电，将电池按正确极性接好，再连接 USB。首次使用按 [ESP-IDF 入门说明](../../../docs/getting-started-idf_ZH.md)准备环境，再在 **`08_battery_voltage`** 目录打开 ESP-IDF 终端。
2. 执行以下命令，第二条会烧录示例并以 **115200 波特率**打开串口监视器。

   ```sh
   idf.py build
   idf.py flash monitor
   ```

3. 直接查看屏幕上的电压，无需触摸操作。

## 预期现象

屏幕和串口约每秒更新一次，显示如 `3.900 V` 的电压和 `ADC` 采样值；这是电压测试，不显示剩余电量百分比。

## 常见问题

- **电压为零或异常：**断电后检查电池连接和极性，需要核对读数时可与万用表比较。
- **为什么没有电量百分比？**本示例只显示电压，不估算剩余电量。
