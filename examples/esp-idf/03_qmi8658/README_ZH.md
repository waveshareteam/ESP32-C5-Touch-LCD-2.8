# QMI8658 运动传感器

[English](README.md) | [简体中文](README_ZH.md)

## 功能

观察移动开发板时加速度和角速度的变化；结果通过串口显示，屏幕不点亮。

## 硬件需求

ESP32-C5-Touch-LCD-2.8 开发板和 USB 数据线，QMI8658 已在板上，无需外接传感器。

## 怎么运行

1. 首次使用按 [ESP-IDF 入门说明](../../../docs/getting-started-idf_ZH.md)准备环境，再在 **`03_qmi8658`** 目录打开 ESP-IDF 终端。
2. 执行以下命令，第二条会烧录示例并以 **115200 波特率**打开串口监视器。

   ```sh
   idf.py build
   idf.py flash monitor
   ```

3. 保持串口监视器打开，先平放开发板，再轻轻倾斜和转动，比较两种状态下的数值。

## 预期现象

串口每 0.5 秒显示 `Accel [g]`（三轴加速度）和 `gyro [deg/s]`（三轴角速度），转动开发板时数值随之变化；静止时仍有重力，不是所有加速度值都为零。

## 常见问题

- **为什么屏幕不亮？**本示例只在串口显示数据，检查屏幕请运行 [01_lvgl_demo](../01_lvgl_demo/README_ZH.md)。
- **没有数值：**保持监视器打开后按 RESET，并检查 [USB 连接和串口设置](../../../docs/getting-started-idf_ZH.md#常见问题)。
