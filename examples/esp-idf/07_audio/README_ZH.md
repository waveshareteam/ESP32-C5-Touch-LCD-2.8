# 触摸屏麦克风录音与回放

[English](README.md) | [简体中文](README_ZH.md)

## 功能

通过触摸屏查看麦克风电平，录制最长 10 秒的声音，再通过扬声器听取录音。

## 硬件需求

ESP32-C5-Touch-LCD-2.8 开发板、USB 数据线及接到扬声器插座的匹配扬声器，无需 SD 卡。

## 怎么运行

1. 先断电接好扬声器，再连接 USB。首次使用按 [ESP-IDF 入门说明](../../../docs/getting-started-idf_ZH.md)准备环境，再在 **`07_audio`** 目录打开 ESP-IDF 终端。
2. 执行以下命令，第二条会烧录示例并以 **115200 波特率**打开串口监视器。

   ```sh
   idf.py build
   idf.py flash monitor
   ```

3. 等待 Record 按钮可用，对着板载麦克风说话，再按下表操作；无需输入串口命令。

## 预期现象

说话时电平条和百分比会变化，按以下方式操作：

| 屏幕按钮 | 操作效果 |
| --- | --- |
| **Record**（录音） | 开始新录音，显示已录时长，上限 **10.0 秒**。 |
| **Stop**（停止） | 提前结束录音，或中止回放；录满 10 秒也会自动停止。 |
| **Play**（播放） | 通过扬声器播放录音，播放结束后可再次点击重听。 |

新录音会覆盖上一段，按 RESET 或断电后录音清除。

## 常见问题

- **Play 是灰色的：**请先录音；录音前的电平监测有显示但不会实时外放声音。
- **回放无声：**检查扬声器接线及录音时长是否大于零，再靠近麦克风重新录一段；当前默认播放音量为 **100/100**。
- **录音能保存吗？**本示例不导出文件，按 RESET 或断电后录音清除。
