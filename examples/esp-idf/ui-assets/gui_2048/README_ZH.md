# 2048 界面源文件

[English](README.md) | [简体中文](README_ZH.md)

## 功能

保存 2048 界面的 GUI Guider 工程和模拟器资源。此目录用于界面编辑，不是 ESP-IDF 固件示例。

## 硬件需求

编辑工程需要安装 NXP GUI Guider 的电脑；运行导出的界面需要开发板。

## 怎么运行

用 GUI Guider 打开 `240x320.guiguider`。开发板程序请从 [02_2048](../../02_2048/README_ZH.md) 编译和烧录。

## 预期现象

编辑器展示 240 × 320 游戏界面，ESP-IDF 示例将界面显示在开发板上。

## 常见问题

附带模拟器使用独立的 LVGL 配置，整合导出的 UI 时须保持开发板示例的 LVGL 版本。
