# PCF85063 实时时钟

[English](README.md) | [简体中文](README_ZH.md)

## 功能

观察板载时钟从预设日期开始计时；结果通过串口显示，屏幕不点亮。

## 硬件需求

ESP32-C5-Touch-LCD-2.8 开发板和 USB 数据线，使用板载 RTC，无需外接时钟模块。

## 怎么运行

1. 首次使用按 [ESP-IDF 入门说明](../../../docs/getting-started-idf_ZH.md)准备环境，再在 **`04_pcf85063`** 目录打开 ESP-IDF 终端。
2. 执行以下命令，第二条会烧录示例并以 **115200 波特率**打开串口监视器。

   ```sh
   idf.py build
   idf.py flash monitor
   ```

3. 在串口监视器中观察秒数递增；按 RESET 后会从预设日期重新开始演示。

## 预期现象

时间从 **2026-10-24 12:00:00** 开始，每秒更新；按 RESET 或重新上电都会重新设置为这个日期，本示例不显示网络实时时间。

## 常见问题

- **日期为什么不是今天？**这是用于演示的固定日期，每次启动都会重新设置，不代表时钟损坏。
- **为什么屏幕不亮？**请在串口监视器看时间，本示例没有屏幕界面。
