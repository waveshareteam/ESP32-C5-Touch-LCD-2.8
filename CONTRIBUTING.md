# Contributing

English | [简体中文](CONTRIBUTING_ZH.md) | [Home](README.md)

Describe the affected example and the behavior before and after your change. Keep board pins and display settings consistent with the schematic. Run the [local checks](docs/ci.md), build affected examples with the configured framework versions, and report hardware tests separately.

Update English and Chinese documentation together. Preserve upstream licenses. Factory BIN files and delivery archives require an intentional release review; example CI does not replace them.

Open a pull request with reproduction steps, framework versions, build results and any remaining hardware checks. Remove credentials and identifying device data from logs.
